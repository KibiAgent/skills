# KibiBot Skills

Plug-and-play skills for AI agents to interact with KibiBot — the on-chain token creation and AI platform.

## Install a skill

Tell your OpenClaw agent:

```
install the kibibot skill from https://github.com/OfficialKibiBot/skills/tree/main/kibibot
```

## Available Skills

| Skill | Description |
|-------|-------------|
| [kibibot](./kibibot) | Create tokens, check earnings, manage LLM credits, and use KibiBot as your AI provider |
